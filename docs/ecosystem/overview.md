
# Ecosystem

Most Layer 2s are built for transactions. House Party Protocol is built for **agents**.

HPP is an AI-native L2 where autonomous agents execute, reason, and pay onchain — and where developers have the tools to build them. Each product below is one layer of that stack.

### OpenHPP · The agent runtime

**Closed beta** — public access coming soon

A secure operating space for AI agents in the HPP family. Autonomous agents run in fully isolated Linux containers, with session-key access control, one-click deployment, and real-time execution visibility.

* Fully isolated Linux containers
* Dynamic session-key access control
* One-click managed deployment

### HPP Router · The model router

**Coming soon**

An LLM inference router for the HPP ecosystem, sending each request to the right model across the network — including HPP Coder.

### HPP Coder · The coding LLM

**Coming soon**

A coding LLM purpose-built for Smart Contract developers in the HPP ecosystem. Served through HPP Router and offered free via HPP Hub.

### HPP Hub · The developer portal

**Live**

Your access point to House Party Protocol's developer tools — and where HPP Coder will be offered free.

→ [hub.hpp.io](https://hub.hpp.io)

### x402 · The payment layer

**Onchain payments**

The open payment standard (HTTP 402) that lets AI agents pay onchain with a single signature — no accounts, no checkout. HPP is registered in the x402 asset registry as a default-asset chain (190415) with USDC settlement, so every agent and app in the ecosystem can transact natively.

→ [HPP and x402: Preparing for the Agentic Payment Era](https://blog.hpp.io/hpp-and-x402-preparing-for-the-agentic-payment-era-part-1/)
