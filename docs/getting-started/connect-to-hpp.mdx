# Connect to HPP

<Tabs>
<TabItem value="mainnet" label="HPP Mainnet">

### HPP Mainnet

#### 🦊 Metamask

**To add HPP Mainnet as a custom network from Block explorer easily:**

1. Visit [HPP Mainnet Block explorer](https://explorer.hpp.io/)
2.  Click the Connect button at the top right.

    ![](/img/image.png)

**To add HPP Mainnet as a custom network to MetaMask manually:**

1. Open the MetaMask browser extension.
2. Open the network selection dropdown menu by clicking the dropdown button at the top of the extension.
3. Click the Add network button.
4. Click Add a network manually.
5. In the Add a network manually dialog that appears, enter the [Network Information](./network-information.mdx)
6. Tap the Save button to save HPP Mainnet as a network.

You should now be able to connect to the HPP Mainnet testnet by selecting it from the network selection dropdown menu.

### Import HPP Token

To import HPP token to Metamask:

1. Open the MetaMask browser extension.
2. Click the drop-down menu at the top right of the token list screen below, then click **`+ Import Token`**.
3. Select the network “HPP Mainnet” added above.
4. Enter the HPP token contract address:
   `0xB48334E7938367bC24Fe1F19000D6f06C622E6c7`
   Click the Next button.
5. After confirming the Token Symbol **HPP** and Decimal **18**, click the **Next button**.
6. Click **Import** to complete.

</TabItem>
