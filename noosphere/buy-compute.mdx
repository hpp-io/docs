# Buy compute

Every Noosphere seller exposes ordinary HTTP endpoints (and MCP tools) priced in USDC.e. You
don't need an account with the seller — just an x402-capable client and a funded wallet.

## 1. Find a service

Browse the [**x402 Explorer**](https://x402-explorer.hpp.io) — the catalog of paid services on
HPP. Each service page shows the price per call, the payment network
(🧪 Sepolia testnet vs Mainnet), an input/output example, and the seller's settlement history.

Prefer code? The explorer's discovery API and MCP server are documented in
[Service directory](/x402/directory).

## 2. Pay from your own code (HTTP)

Any x402 client works — the standard `@x402` SDK with HPP's network registered:

```ts
import { x402Client } from "@x402/core/client";
import { ExactEvmScheme } from "@x402/evm/exact/client";
import { wrapFetchWithPayment } from "@x402/fetch";

const client = new x402Client().register("eip155:181228", new ExactEvmScheme(account));
const paidFetch = wrapFetchWithPayment(fetch, client);

const r = await paidFetch("https://agent-sepolia.hpp.io/paid/compute/sentiment", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ text: "I love this" }),
});
const { output, receipt } = await r.json();
```

The first request returns `402` with payment terms; the wrapper signs a USDC.e authorization
(no gas needed) and retries. Full setup — accounts, funding, mainnet:
[**x402 buyer quickstart**](/x402/quickstart-buyers).

## 3. Pay from an AI agent (MCP)

Seller services double as MCP tools (`compute_<service>`). Claude, Cursor, or any MCP host can
call them and pay autonomously through the
[x402 MCP bridge](/x402/agents) — including a capped wallet setup with no code.

## What you can rely on

- **Bad input costs nothing** — sellers validate your body against their input schema and reject
  with `400` *before* any payment.
- **Failures cost nothing** — payment settles only after a successful response; a failed MCP
  tool call cancels the payment.
- **Receipts** — services with receipts enabled return a verifiable record binding your exact
  request, the result, and the on-chain settlement transaction.
